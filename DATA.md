# JRDB data

The files under `data/jrdb_2dbox/` are processed JRDB trajectory and 2D bounding
box data in ndjson format.

Included split files:

- train: 10 files
- validation: 1 file
- test: 2 files

JRDB is published under the Creative Commons
Attribution-NonCommercial-ShareAlike 3.0 license. Users of these files must
follow the dataset license and cite JRDB.
